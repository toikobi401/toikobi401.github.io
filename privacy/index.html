Privacy Policy

Last updated: November 19, 2026

This policy explains what data Rift Arena Publisher (the "App") handles. The App is a private tool used only by the Rift Arena channel owner to publish videos to their own TikTok account.

1. Data the App receives from TikTok

  • OAuth access and refresh tokens for the owner's TikTok account.
  • Basic profile information (open ID, display name, avatar) from the user.info.basic scope.
  • The status of videos the App uploads (video.publish) and statistics for videos on the owner's account, such as views, likes, comments and shares (video.list).

2. How the data is used

The data is used only to publish the owner's videos, confirm that each post succeeded, and show the owner how their videos perform. It is not used for advertising or profiling.

3. Storage

Tokens and statistics are stored on the owner's own computer. Tokens are stored encrypted. Nothing is stored on this website or sent to any third party.

4. Sharing

The App does not sell, share or transfer data to anyone. It only exchanges data with TikTok to perform the actions above.

5. Visitors to this website

This website is a static site hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log technical data such as IP addresses; see the GitHub Privacy Statement.

6. Retention and deletion

The owner can revoke the App's access at any time in TikTok settings under Security and permissions → Apps and services. When access is revoked or no longer needed, the stored tokens are deleted.

7. Contact

Contact the owner through GitHub: github.com/toikobi401.
